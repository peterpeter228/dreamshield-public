## Nonextension local SL runner — offline verified, real G1 NOT_RUN

`npm run local:stop -- <command>` is a non-listening, chain-50383, **EOA-only** CLI. It cannot protect Wallet1 Safe. Wallet1 Safe control is a separate prerequisite: never substitute the old F36E owner, a new funded EOA or old credentials. This implementation adds no execution permission.

```sh
npm run local:stop -- inspect --owner <public-address> --pool <public-address>
npm run local:stop -- plan --owner <public-address> --pool <public-address> --trigger <decimal>
npm run local:stop -- prepare --owner <public-address> --pool <public-address> --trigger <decimal> --request-id <uuid>
npm run local:stop -- send --operation <uuid> --confirm <prepared-plan-digest>
npm run local:stop -- reconcile --operation <uuid>
```

Public inspect/plan/prepare/reconcile never consume the key variable. Plan does not reserve, recover or mutate journal operations/events. Prepare reserves only Draft, persists the immutable plan event and returns the original result for an identical request; changed terms refuse. The address-only SDK wallet denies every transport method. Only whole-position reduce-only create-SL is admitted, with canonical draft validation and sensible SL distance. Missing operator authorization refuses without creating an approval capability. No grant/cancel/open/fund/raw-calldata command exists; unknown options refuse.

`DREAMSHIELD_LOCAL_STOP_DIR` selects an isolated durable local directory (default `.dreamshield-local-stop`), not the server journal. Mutating invocations hold an exclusive `invocation.lock`; contention or a stale lock refuses. Never delete an unresolved journal or lock to retry a send. Establish that its prior process has stopped and reconcile the original operation through an authorized recovery procedure. AwaitingSignature/Reconcile recover to Unknown; Unknown/NeedsReview retain the owner lock. A missing immutable plan refuses sending rather than reconstructing it.

The already-authorized native launcher alone may inject the nonsecret `DREAMSHIELD_G1_POLICY_PATH` (absolute regular file, no final symlink, ≤16 KiB), `DREAMSHIELD_G1_POLICY_SHA256` (lowercase exact-byte SHA256) and `DREAMSHIELD_G1_AUTHORIZATION_ID` (1–128 ASCII letters/digits/`_.:-`). Partial/missing binding yields an explicitly unready unsigned plan. Bad supplied policy fails, not a fallback. The artifact, matching hash or confirmation digest **does not grant authority**. Same-OS environment control is inside the existing native-launcher trust boundary; no frontend policy input is accepted.

Ready public preparation chooses the exact live EIP-1559 fees and exact bounded gas estimate; it never clips or pads them. The plan binds source, expiry, public sender, nonce, gas, fees, deposit, all caps, policy hash/identity and request/operation identity. Simulation uses the same public endpoint with literal `eth_call`/`eth_estimateGas`, explicit hex quantities/type `0x2`, the full envelope and pinned block; malformed/unsupported results fail closed. Require `value + gas * maxFeePerGas ≤ maxTotalCost` and sufficient native balance.
